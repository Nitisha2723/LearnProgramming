# Java Knowledge Checks

Interactive quizzes for every module — open any HTML file directly in your browser, no server needed.

Each quiz has 15 questions: multiple choice, true/false, code-output ("what does this print?"), and fill-in-the-blank. Instant feedback after every answer, with a full explanation of why. Final score screen with grade + "Review Wrong Answers" mode.

| Module | Quiz | Topics |
|--------|------|--------|
| 01 | [Foundations](01-foundations-quiz.html) | JVM/JDK/JRE, primitives, type casting, String basics, operators |
| 02 | [Core Language](02-core-language-quiz.html) | Loops, arrays, ArrayList, String methods, method overloading |
| 03 | [OOP](03-oop-quiz.html) | Classes, inheritance, polymorphism, abstract vs interface, access modifiers |
| 04 | [Data Structures](04-data-structures-quiz.html) | HashMap, ArrayList, Stack, Queue, Big-O complexity |
| 05 | [Real-World](05-real-world-quiz.html) | Streams, Optional, exceptions, lambdas, Mockito |
| 06 | [Software Design](06-design-quiz.html) | SOLID (with violation code snippets), GoF patterns, code smells |
| 07 | [Advanced](07-advanced-quiz.html) | Generics, concurrency, CompletableFuture, Java 21 features |
| 08 | [Projects](08-projects-quiz.html) | Repository pattern, MVC, Service layer, dependency injection |
| 09 | [Interview Prep](09-interview-prep-quiz.html) | Big-O, system design, String pool gotchas, CAP theorem |

## Grading Scale

| Score | Grade |
|-------|-------|
| 95–100% | Expert! |
| 80–94% | Good Job! |
| 60–79% | Getting There |
| 0–59% | Needs Work |

## How to Use

1. Open any `.html` file in your browser (`file://` works fine)
2. Answer each question — get instant feedback + explanation
3. Use **Review Wrong Answers** at the end to drill your weak spots
4. Keyboard shortcuts: Arrow keys select options, Enter/Space confirm, A/B/C/D for quick pick
