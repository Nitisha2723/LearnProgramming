# Exercises

Practice problems for Module 02 — Core Language.

## How to Approach These

1. Read the exercise file carefully — each TODO explains exactly what to implement
2. Run the `main()` method to see what output is expected
3. Implement the TODOs one at a time
4. Compare your output to the expected output in the comments
5. Only look at solutions after a genuine attempt!

## Exercises

| File | Topic | Difficulty |
|------|-------|------------|
| `Exercise01_FizzBuzz.java` | Loops, conditions, counters | Beginner |
| `Exercise02_Loops.java` | Nested loops, while loops, math | Beginner-Intermediate |
| `Exercise03_Methods.java` | String methods, method design | Intermediate |
| `Exercise04_Arrays.java` | Array algorithms, two pointers | Intermediate |

## Solutions

Solutions are in `solutions/`. Check them only after you've made a real attempt.

The solutions are written to be clear and well-commented — even if your solution works, compare it to the solution to see if there's a cleaner approach.

## Tips

- If you're stuck, re-read the HINTS section in each exercise file
- Remember: `%` is the modulo (remainder) operator — essential for FizzBuzz and digit reversal
- For String problems, check `theory/04-strings-in-depth.md`
- For array problems, check `theory/03-arrays.md`
