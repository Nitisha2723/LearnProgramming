# Code Examples

Runnable Java programs demonstrating the concepts from the `theory/` guides.

## Files

| File | Demonstrates |
|------|-------------|
| `ControlFlowDemo.java` | if/else, ternary, switch, while, do-while, for, for-each, break/continue, nested loops |
| `MethodsDemo.java` | void methods, return values, overloading, recursion, pass-by-value |
| `ArraysDemo.java` | Array declaration, iteration, searching, sorting, 2D arrays, Arrays utility |
| `StringsDemo.java` | String immutability, == vs equals, all String methods, StringBuilder, formatting |

## How to Compile and Run

```bash
# Compile one file
javac ControlFlowDemo.java

# Run it
java ControlFlowDemo

# Compile all at once
javac *.java
```

## Reading Order

1. Read the matching theory guide
2. Run the demo program and observe the output
3. Experiment: modify values and re-run to test your understanding

## Tips for Learning from These Files

- Every section is separated by clearly labeled comments
- Comments explain WHY, not just WHAT
- Look for the `// IMPORTANT` and `// NOTE` comments — they highlight gotchas
- The output is designed to be self-explanatory — read it alongside the code
