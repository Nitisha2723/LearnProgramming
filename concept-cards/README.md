# Concept Cards

Interactive flashcard-style concept cards for Java, Python, and system design interview preparation.

## Flashcard Sets

| File | Cards | Categories |
|------|-------|------------|
| [java-flashcards.html](java-flashcards.html) | 50+ | Core Java, OOP, Collections, Concurrency, Java 8+ |
| [python-flashcards.html](python-flashcards.html) | 55+ | Core Python, OOP, Data Structures, Functional, Async |
| [interview-flashcards.html](interview-flashcards.html) | 30 | System Design, Behavioral, CS Fundamentals |

## Features

- **Card flip animation** — CSS 3D perspective transform (genuine flip effect)
- **Progress tracker** — track how many cards reviewed
- **Mark cards** — "Know it ✓", "Review again ↺", "Hard !"
- **Category filter** — filter by topic category
- **Keyboard navigation** — ← → to navigate, Space to flip
- **Dark theme** — consistent with cheat sheets

## Study Tips

1. Go through all cards once quickly to identify weak areas
2. Mark cards as "Hard" or "Review again" for a second pass
3. Use category filters to focus on specific topics before an interview
4. Return to "Hard" cards after a day to test retention (spaced repetition)
