# Python Knowledge Checks

Interactive quizzes for every module — open any HTML file directly in your browser, no server needed.

Each quiz has 15 questions: multiple choice, true/false, code-output ("what does this print?"), and fill-in-the-blank. Instant feedback after every answer, with a full explanation of why. Final score screen with grade + "Review Wrong Answers" mode.

| Module | Quiz | Topics |
|--------|------|--------|
| 01 | [Foundations](01-foundations-quiz.html) | Dynamic typing, f-strings, truthiness, `is` vs `==`, floor division |
| 02 | [Core Language](02-core-language-quiz.html) | Slicing, list methods, unpacking, `*args/**kwargs`, string methods |
| 03 | [OOP](03-oop-quiz.html) | `__init__`, `@property`, dunder methods, ABC, Protocol, `@dataclass`, MRO |
| 04 | [Data Structures](04-data-structures-quiz.html) | Counter, defaultdict, deque, comprehensions, Big-O |
| 05 | [Real-World](05-real-world-quiz.html) | Generators, context managers, itertools, exception flow, file I/O |
| 06 | [Software Design](06-design-quiz.html) | SOLID (Python code violations), decorators, patterns, ABC vs Protocol |
| 07 | [Advanced](07-advanced-quiz.html) | asyncio, GIL, closures, `nonlocal`, metaclasses, descriptors, `__slots__` |
| 08 | [Projects](08-projects-quiz.html) | Generator pipelines, type hints, pathlib, packaging, `if __name__` |
| 09 | [Interview Prep](09-interview-prep-quiz.html) | Classic gotchas: mutable defaults, late binding, `is` vs `==`, GIL, BFS |

## Grading Scale

| Score | Grade |
|-------|-------|
| 95–100% | Expert! |
| 80–94% | Good Job! |
| 60–79% | Getting There |
| 0–59% | Needs Work |

## How to Use

1. Open any `.html` file in your browser (`file://` works fine)
2. Answer each question — get instant feedback + explanation
3. Use **Review Wrong Answers** at the end to drill your weak spots
4. Keyboard shortcuts: Arrow keys select options, Enter/Space confirm, A/B/C/D for quick pick
