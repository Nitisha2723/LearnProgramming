## What You Will Learn

- Lists: creation, indexing, slicing, methods, sorting
- Tuples: immutability, when to use tuples vs lists
- Dictionaries: creation, access, methods, iteration, nested dicts
- Sets: unique collections, set operations (union, intersection, difference)
- List comprehensions: the Pythonic way to build lists
- Dictionary comprehensions and set comprehensions
- Generators: lazy evaluation, `yield`, generator expressions
- Iterators and the iterator protocol
- Collections module: `Counter`, `defaultdict`, `OrderedDict`, `deque`
- When to use each data structure — decision guide
