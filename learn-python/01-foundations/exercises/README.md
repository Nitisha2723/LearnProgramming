# Exercises: 01-foundations

This directory contains three exercises for the foundations module. Work through them in order.

## Instructions

1. Open each exercise file and read the instructions at the top.
2. Write your code below the instructions — do NOT look at the solution first.
3. Run your code: `python3 exercise_XX_name.py`
4. Fix any errors and re-run until your output matches the expected output.
5. Only then open the corresponding solution file to compare approaches.

## Exercises

| Exercise | File | Focus |
|----------|------|-------|
| Exercise 1 | `exercise_01_hello_world.py` | print(), variables, f-strings |
| Exercise 2 | `exercise_02_variables.py` | Multiple variables, data types, formatted output |
| Exercise 3 | `exercise_03_calculator.py` | All arithmetic operators, output formatting |

## Solutions

Solutions are in the `solutions/` subdirectory. Look at them AFTER you have tried each exercise yourself.

Do not skip the struggle. The process of figuring it out yourself is where the learning happens.

## Running the Exercises

```bash
# From the repository root:
python3 01-foundations/exercises/exercise_01_hello_world.py
python3 01-foundations/exercises/exercise_02_variables.py
python3 01-foundations/exercises/exercise_03_calculator.py
```

## What to Do When Stuck

1. Re-read the exercise instructions carefully
2. Look back at the relevant code example in `../code/`
3. Try things in the REPL: `python3`
4. Read the error message carefully — it tells you what went wrong and on which line
5. Search "Python [error type]" — learning to search effectively is a core skill

Only look at the solution as a last resort. Even a broken, half-working attempt teaches you more than reading the answer.
