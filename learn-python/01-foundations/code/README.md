# Code Examples: 01-foundations

This directory contains working Python programs that demonstrate the concepts from the theory files. Read the theory first, then study these examples.

## How to Use These Files

1. **Read each file** — read every comment. The comments are the lesson.
2. **Type it yourself** — do not copy-paste. Typing forces you to pay attention to syntax.
3. **Run it** — see the output and understand why you see what you see.
4. **Modify it** — change values, break things, see what happens. Experimentation is learning.

## Files

| File | What It Covers |
|------|----------------|
| `hello_world.py` | Your first Python program: print(), variables, f-strings |
| `data_types_demo.py` | int, float, str, bool, None, type(), type conversion |
| `operators_demo.py` | Arithmetic, comparison, logical, and assignment operators |

## Running the Examples

```bash
# From the repository root:
python3 01-foundations/code/hello_world.py
python3 01-foundations/code/data_types_demo.py
python3 01-foundations/code/operators_demo.py
```

## What to Do While Reading

Open the Python REPL alongside the examples:

```bash
python3
```

Try variations as you read. If you see `x = 42` in the example, try `x = 100` in the REPL. If you see `type(x)`, try `type("hello")`, `type(3.14)`, `type(True)`.

The REPL is your sandbox. Nothing you type there can break anything permanently.
