# Exercises

Four progressive exercises that build on the theory you have just read.

## Before You Start

- Attempt each exercise fully before looking at the solution
- The point is to struggle productively — that is where learning happens
- If you are completely stuck after 20 minutes, peek at the solution and understand it, then close it and rewrite it yourself

## Exercise Overview

| File | Topic | Concepts |
|------|-------|----------|
| `exercise_01_fizzbuzz.py` | FizzBuzz with statistics | if/elif/else, modulo, loops, counters |
| `exercise_02_loops.py` | Loop patterns | nested loops, range, math, string manipulation |
| `exercise_03_functions.py` | String utilities | pure functions, string operations, iteration |
| `exercise_04_lists.py` | List algorithms | list manipulation, sets, two-pointer technique |

## How to Run Your Solutions

```bash
# Run any exercise file
python exercises/exercise_01_fizzbuzz.py

# Run tests against your solutions (from 02-core-language directory)
pytest tests/ -v
```

## Solutions

Solutions are in `exercises/solutions/`. Resist peeking until you have a working attempt!
Each solution is documented with explanations of the approach.
