## What You Will Learn

- Classes and objects: the fundamental OOP concepts
- `__init__` and instance variables
- Methods: instance, class, and static methods
- Inheritance and `super()`
- Encapsulation and name mangling
- Polymorphism and duck typing
- Magic methods (dunder methods): `__str__`, `__repr__`, `__len__`, `__eq__`, and more
- Dataclasses for clean, modern Python OOP
- Abstract classes and interfaces with `abc`
