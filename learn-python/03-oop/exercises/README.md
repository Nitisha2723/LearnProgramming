# Exercises

## How to Use

1. Read the exercise file — it contains the specification, starter code, and hints
2. Implement the required classes and methods
3. Run the exercise file to test your work (it includes a basic test)
4. Check the `solutions/` directory if you're stuck (try first!)
5. Run `pytest ../tests/` to run all automated tests

## Exercises

| Exercise | Topic | Difficulty |
|----------|-------|------------|
| `exercise_01_library.py` | Classes, properties, `__str__`, `__eq__` | Beginner |
| `exercise_02_vehicles.py` | Inheritance, `super()`, ABC, polymorphism | Intermediate |
| `exercise_03_payment_system.py` | Protocols, multiple classes, complex logic | Advanced |

## Tips

- Start with `__init__` — get the attributes right first
- Add `__str__` early — it makes debugging much easier
- Use `@property` instead of `get_` methods
- Write the tests (or run them) as you go, not just at the end
- The solutions show one correct approach — there are often other valid solutions
