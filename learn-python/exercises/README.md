# Cross-Module Exercises

**Status:** Coming Soon

---

## Overview

This directory will contain exercises that span multiple modules — problems that require combining concepts from different parts of the curriculum.

These exercises are intended for learners who have completed multiple modules and want to integrate their knowledge.

## Planned Exercise Sets

### Beginner Integration (after Modules 01–02)
- Build a simple number guessing game
- Create a text-based quiz
- Write a unit converter (meters to feet, Celsius to Fahrenheit)

### Intermediate Integration (after Modules 01–04)
- Implement a simple contact book using dictionaries
- Build a word frequency counter for a text file
- Create a simple inventory management system

### Advanced Integration (after Modules 01–07)
- Design and implement a cache with LRU eviction
- Build a simple event system with decorators
- Implement a command pattern for an undo/redo system

## How These Differ from Module Exercises

Module exercises focus on one concept at a time. These cross-module exercises are deliberately open-ended — they do not tell you exactly how to implement the solution. You must choose the right tools, design the structure, and write clean code on your own.

This is the closest thing to real-world programming practice in this repository.
