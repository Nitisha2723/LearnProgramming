# Tree Problems

10 binary tree interview problems with Python implementations.

| # | Problem | Key Technique | Complexity |
|---|---------|--------------|------------|
| 1 | Maximum Depth | DFS recursion | O(n) |
| 2 | Same Tree | DFS recursion | O(n) |
| 3 | Invert Binary Tree | DFS recursion | O(n) |
| 4 | Level Order Traversal | BFS with queue | O(n) |
| 5 | Validate BST | DFS with bounds | O(n) |
| 6 | LCA of BST | BST property | O(h) |
| 7 | Right Side View | BFS, last per level | O(n) |
| 8 | Count Good Nodes | DFS with running max | O(n) |
| 9 | Diameter of Binary Tree | DFS, track max | O(n) |
| 10 | Serialize/Deserialize | DFS pre-order | O(n) |

See `tree_problems.py` for complete implementations.
