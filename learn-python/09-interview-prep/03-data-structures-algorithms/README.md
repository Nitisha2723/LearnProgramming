## Complexity Reference

| Operation | Array | Hash Map | Linked List | BST (balanced) |
|-----------|-------|---------|-------------|----------------|
| Access | O(1) | O(1) | O(n) | O(log n) |
| Search | O(n) | O(1) | O(n) | O(log n) |
| Insert | O(n) | O(1) | O(1) | O(log n) |
| Delete | O(n) | O(1) | O(1) | O(log n) |

## Study Tips

1. Write the brute-force first, then optimise
2. Always state Big O before coding
3. Test with: empty input, single element, duplicates, negatives
4. Know the Python-specific idioms: `collections.Counter`, `heapq`, `bisect`
