# Array Problems

10 array interview problems with optimal Python solutions.

| # | Problem | Key Technique | Complexity |
|---|---------|--------------|------------|
| 1 | Two Sum | Hash map | O(n) |
| 2 | Best Time to Buy and Sell Stock | Sliding window / greedy | O(n) |
| 3 | Contains Duplicate | Set | O(n) |
| 4 | Product of Array Except Self | Prefix/suffix products | O(n) |
| 5 | Maximum Subarray | Kadane's algorithm | O(n) |
| 6 | Maximum Product Subarray | Track min and max | O(n) |
| 7 | Find Minimum in Rotated Sorted Array | Binary search | O(log n) |
| 8 | Search in Rotated Sorted Array | Binary search | O(log n) |
| 9 | 3Sum | Sort + two pointers | O(n²) |
| 10 | Container With Most Water | Two pointers | O(n) |

See `array_problems.py` for complete implementations.
