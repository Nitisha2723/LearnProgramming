# String Problems

10 string interview problems with optimal Python solutions.

| # | Problem | Key Technique | Complexity |
|---|---------|--------------|------------|
| 1 | Valid Anagram | Counter | O(n) |
| 2 | Valid Palindrome | Two pointers | O(n) |
| 3 | Longest Substring Without Repeating | Sliding window | O(n) |
| 4 | Longest Repeating Character Replacement | Sliding window | O(n) |
| 5 | Minimum Window Substring | Sliding window + counter | O(n+m) |
| 6 | Group Anagrams | Sort as key | O(n k log k) |
| 7 | Encode and Decode Strings | Length-prefixed encoding | O(n) |
| 8 | Palindromic Substrings | Expand around center | O(n²) |
| 9 | Longest Palindromic Substring | Expand around center | O(n²) |
| 10 | Valid Parentheses | Stack | O(n) |

See `string_problems.py` for complete implementations.
