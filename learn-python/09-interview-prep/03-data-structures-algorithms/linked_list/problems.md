# Linked List Problems

10 linked list interview problems with Python implementations.

| # | Problem | Key Technique | Complexity |
|---|---------|--------------|------------|
| 1 | Reverse Linked List | Three-pointer iterative | O(n) |
| 2 | Detect Cycle | Floyd's tortoise and hare | O(n), O(1) |
| 3 | Merge Two Sorted Lists | Dummy head + compare | O(n+m) |
| 4 | Merge K Sorted Lists | Min-heap | O(N log k) |
| 5 | Remove Nth Node From End | Two-pointer offset | O(n) |
| 6 | Reorder List | Middle + reverse + merge | O(n) |
| 7 | Find Middle | Slow/fast pointers | O(n) |
| 8 | Palindrome Linked List | Reverse half + compare | O(n), O(1) |
| 9 | Intersection of Two Lists | Dual pointer switch | O(n+m) |
| 10 | LRU Cache | OrderedDict | O(1) get/put |

See `linked_list_problems.py` for complete implementations.
