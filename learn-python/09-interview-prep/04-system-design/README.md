## Interview Framework (15-min version)

1. **Clarify requirements** (2 min) — functional + non-functional, scale
2. **Estimate scale** (2 min) — QPS, storage, bandwidth
3. **API design** (2 min) — main endpoints
4. **High-level design** (4 min) — components and data flow
5. **Deep dive** (4 min) — pick 1-2 bottlenecks and solve them
6. **Wrap up** (1 min) — failure modes, monitoring, future improvements
