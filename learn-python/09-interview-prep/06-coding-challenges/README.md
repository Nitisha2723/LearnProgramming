# Coding Challenges

Thirteen problems with complete Python solutions, time/space complexity
analysis, and test cases.

## Structure

```
easy/    — 5 problems (< 20 min each)
medium/  — 5 problems (20-45 min each)
hard/    — 3 problems (45-60 min each)
```

## Difficulty Guide

| Difficulty | Focus |
|-----------|-------|
| Easy | Core data structure manipulation, simple logic |
| Medium | Combining data structures, optimisation |
| Hard | Advanced algorithms, multiple techniques combined |

## How to Use

1. Read the problem.
2. Try to solve it yourself first (set a timer).
3. If stuck, read the hints in the solution file.
4. After solving, check the solution and complexity analysis.
