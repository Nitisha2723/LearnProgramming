## Python-Specific Interview Tips

1. **Know the data model** — `__dunder__` methods, `__slots__`, descriptors
2. **Complexity matters** — Always state Big O for your solutions
3. **Pythonic matters** — Interviewers notice list comprehensions vs. explicit loops
4. **Type hints** — Use them; they signal professional code
5. **Testing mindset** — Mention edge cases proactively
6. **Standard library** — Know `collections`, `itertools`, `functools`, `heapq`
