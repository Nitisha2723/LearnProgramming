Pseudocode

bubbleSort(arr): n = arr.length for i = 0 to n-1: swapped = false for j = 0 to n-i-2: // compare neighbors if arr[j] > arr[j+1]: swap(arr[j], arr[j+1]) swapped = true if not swapped: break return arr
