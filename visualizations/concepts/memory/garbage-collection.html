Mark & Sweep Algorithm

1
GC starts from GC Roots (stack variables, static fields) — these are always reachable.
2
MARK phase: GC traverses every object reachable from roots (following all reference arrows), marks each one green.
3
SWEEP phase: Any object NOT marked (unreachable = no path from roots) is garbage. GC frees its memory.
!
Key insight: An object is eligible for GC when zero reachable references point to it — not when you're "done with it". Objects can keep each other alive if they form an isolated cycle with no root connection.
