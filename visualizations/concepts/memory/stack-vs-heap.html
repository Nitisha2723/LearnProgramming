Stack Memory

LIFO (Last In, First Out) — the last frame pushed is first popped.
Stores local variables, method parameters, and references (pointers to heap objects).
When a method returns, its entire frame is instantly removed.

Fast: just moves a stack pointer. Fixed size (typically 512KB–1MB per thread).

Heap Memory

Dynamic — objects allocated anywhere with new.
Objects survive across method calls until no more references point to them.
When a stack frame is removed, if no other variable holds the reference, the object becomes eligible for Garbage Collection.

Slower: needs memory manager. Much larger (configured with -Xmx flag).
